## 0.10.0 — 2026-11-06

### Added

- **Add opt-in complete Gmail search pagination with bounded pages and explicit incomplete-search errors** (`createGmailClient`, `GmailClient`)

## 0.9.0 — 2026-11-06

### Added

- **Add host-controlled Gmail sending with bounded MIME attachments and explicit uncertain outcomes** (`buildOutgoingMime`, `sendGmailMessage`, `EmailSendError`)
  Hosts inject authorized transport and own approvals and durable execution. Sends are attempted once; ambiguous outcomes require reconciliation.

## 0.8.0 — 2026-11-05

### Breaking

- **Fail Gmail reads explicitly and preserve cursors on incomplete history** (`createGmailClient`, `GmailClient`)
  _Migration:_ Catch Gmail read and watch failures instead of treating null or empty results as successful reads. Commit history messages and its returned cursor atomically only after success. Set maxPages up to 100 for larger history batches; preserve the old cursor on any error.

## 0.7.1 — 2026-10-08

### Fixed

- **Validate Gmail push payloads and keep large history cursors exact (the 0.4.1 fix, now on the current line)** (`parseGmailPubSubWebhook`)
  The Gmail push validation fix shipped as 0.4.1 on the older 0.4 line, so 0.6 and 0.7 never had it. Gmail Pub/Sub push payloads are validated, and numeric history cursors are normalized only when they are safe integers, so a large cursor is never rounded.

## 0.7.0 — 2026-09-25

### Added

- **Add opt-in `selection: "newest"` for verification lookups: use the most recent authenticated match (up to a 24-hour window) instead of failing on multiple matches, and keep Gmail's newest candidates on busy inboxes. The default remains strict unique matching.** (`EmailVerificationLookupInput`, `resolveEmailVerificationCode`, `retrieveEmailVerificationCode`, `createGmailVerificationMessageLookup`)

## 0.6.0 — 2026-09-24

- **Verification profiles can explicitly match standalone code lines after a trusted marker; HTML normalization can preserve block boundaries.** (`EmailVerificationProfile`, `stripHtml`)

## 0.4.1 — 2026-09-27

### Fixed
